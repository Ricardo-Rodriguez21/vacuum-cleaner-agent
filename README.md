# Lab 1 — Vacuum Cleaner Agent (4 rooms)

این مخزن بر اساس دو نوت‌ بوک آزمایشگاه ارائه‌ شده تهیه شده است

## فایل‌ها
- `lab1_vacuum_agent.ipynb`: نسخهٔ اصلی آزمایش
- `lab1_vacuum_agent_completed.ipynb`: نسخهٔ تکمیل‌ شده شامل ثبت فریم‌ها و انیمیشن عامل‌ها و نمودار میله‌ای

## اجرای Google Colab
1. وارد https://colab.research.google.com/ شوید.
2. از File → Upload notebook یکی از فایل‌های بالا را بارگذاری کنید.
3. سلول‌ها را به ترتیب اجرا کنید؛ در Colab می‌توانید از Runtime → Run all استفاده کنید.
4. خروجی جدول `summary` و نمودار را ذخیره کنید.
5. در نسخهٔ تکمیل‌شده، سلول‌های انتهایی انیمیشن حرکت عامل‌ها و نمودار میله‌ای متحرک را نمایش می‌دهند.

## پارامترهای آزمایش
- تعداد اتاق‌ها: `N_ROOMS = 4`
- تعداد گام‌ها در هر اجرا: `STEPS = 50`
- تعداد اجرا برای هر عامل: `RUNS = 100`
- عامل‌ها: `random`، `reflex` و `model`

## PEAS مطابق نوت‌بوک
- **Performance:** امتیاز +۱ برای هر اتاق تمیز در هر گام
- **Environment:** چهار اتاق با آلودگی اولیهٔ تصادفی
- **Actuators:** `Left`، `Right`، `Suck`، `NoOp`
- **Sensors:** موقعیت عامل و وضعیت اتاق فعلی

## تعریف امتیاز
در هر گام، تعداد اتاق‌های تمیز به امتیاز اضافه می‌شود. بنابراین امتیاز، جمع تعداد اتاق‌های تمیز در طول اجراست، نه فقط تعداد اتاق‌های تمیز در انتهای اجرا.

## نکته دربارهٔ نتایج
اعداد واقعی را پس از اجرای نوت‌بوک از جدول `summary` بردارید. خروجی‌های اجرانشده نباید به‌عنوان نتایج آزمایش گزارش شوند.
